02

Future vision

RDP UI becomes the default answer to “how do I make my Django app beautiful without a frontend team?”

The Django-native choice

When a tutorial, a Stack Overflow answer, or the Django forum needs UI, it reaches for <c-rdp.*> the way it reaches for the ORM — because it fits the framework's grain, not despite it.

Backend engineers ship product

A solo developer takes an idea from startproject to a polished, accessible, themeable SaaS — templates, HTMX, and RDP UI. No build step, no JS framework, no designer on payroll.

Enterprise standard

Internal tools — ERP, CRM, HRM, admin panels — stop looking like 2009. One token system, one component contract, every team's tools consistent and WCAG AA by default.
