RDP Starter Kit

Template project Django production-ready untuk semua produk Radian Data Platform. Clone dan langsung fokus ke fitur bisnis dalam < 5 menit — auth, dashboard, UI system, dan deployment sudah dikonfigurasi.

GitHub → Lihat Contoh →
{# ─────────────── INSTALL ─────────────── #}

Instalasi

Butuh Python 3.11+ dan uv.

Cara 1 — Clone langsung

git clone https://github.com/radianapp/starterkit nama-project
cd nama-project
cp .env.example .env
# Edit SECRET_KEY di .env
uv sync
uv run python manage.py migrate
uv run python manage.py createsuperuser
uv run python manage.py runserver

Cara 2 — Via RDP CLI (bootstrap wizard)

# Install CLI global sekali saja
uv tool install git+https://github.com/radianapp/starterkit.git

# Bootstrap project baru interaktif
rdp new nama-project

Wizard akan tanya nama, deskripsi, warna aksen, dan fitur yang disertakan (landing page, auth, dashboard).

{# ─────────────── STRUCTURE ─────────────── #}

Struktur Folder

apps/
  core/         # context processors, mixins, base views
  accounts/   # Custom User, auth views, profile
  dashboard/  # halaman utama post-login
config/
  settings/
    base.py    # settings utama
    dev.py     # SQLite, DEBUG=True, email console
    production.py # PostgreSQL, SMTP, security headers
templates/
  cotton/     # komponen <c-rdp.*> dan layout
  apps/       # template per app
static/       # CSS, JS, vendor assets
scripts/
  rdp_cli.py  # source CLI

Setiap app menggunakan package per fungsi — bukan file flat. models/, views/, services/, forms/, admin/ masing-masing folder dengan __init__.py. Logic bisnis wajib di services/.

{# ─────────────── RDP-UI ─────────────── #}

RDP-UI & Tema

CSS framework berbasis PicoCSS v2 + custom design tokens. 11 tema bawaan. Dimuat via CDN atau self-host.

CDN (default)

# .env
RDP_UI_VERSION=v1.0
RDP_UI_SELF_HOST=False

Self-host (development)

RDP_UI_SELF_HOST=True
# Aset dimuat dari static/vendor/rdp-ui/

Ganti tema

# Di template — set atribut di <html>
<html data-rdp-theme="dark" data-theme="dark">

# Via JS
rdpSetTheme('midnight')

# Tema tersedia: default, light, dark, midnight, nord,
# dracula, forest, ocean, corporate, github, terminal

Docs lengkap RDP-UI: ui.radian.web.id

{# ─────────────── AUTH ─────────────── #}

Auth

Auth lengkap sudah dikonfigurasi — login, register, logout, forgot password, profile settings, email verifikasi. Custom User model extend AbstractUser.

URLFungsi
/accounts/login/Halaman login
/accounts/register/Registrasi akun baru
/accounts/logout/Logout (POST)
/accounts/profile/Edit profil & ganti password
/accounts/password-reset/Request reset password via email

Custom User model

# config/settings/base.py
AUTH_USER_MODEL = "accounts.User"

# apps/accounts/models/user.py — extend di sini
class User(AbstractUser):
  # tambah field custom di sini
  pass

Penting: jangan ubah AUTH_USER_MODEL setelah ada data di database.

{# ─────────────── HTMX ─────────────── #}

HTMX

HTMX + Alpine.js sudah dimuat di <c-layout.base>. Tidak butuh konfigurasi tambahan.

Pattern partial response

# views.py — kembalikan fragment untuk HTMX, full page untuk browser biasa
def my_view(request):
  if request.htmx:
    return render(request, "app/partials/list.html", ctx)
  return render(request, "app/list.html", ctx)

Error form via HTMX

# Gunakan HTTP 422 agar HTMX tahu ini error
return render(request, "form_partial.html", ctx, status=422)

Redirect setelah sukses

from django_htmx.http import HttpResponseClientRedirect
return HttpResponseClientRedirect("/dashboard/")

Lihat 10 pola HTMX dengan contoh interaktif di /examples/htmx/.

{# ─────────────── CLI ─────────────── #}

RDP CLI

Generator kode interaktif. Install global sekali, pakai di semua project RDP.

uv tool install git+https://github.com/radianapp/starterkit.git
PerintahFungsi
rdp new <nama>Bootstrap project baru dari template (wizard interaktif)
rdp new app <nama>Django app baru dengan struktur package (models/, views/, services/…)
rdp new model <nama> -a <app>File model baru + auto-export di __init__.py
rdp new crud <nama> -a <app>ListView + CreateView + UpdateView + DeleteView + template
rdp new api <app>Skeleton DRF: api/views/, api/serializers/, api/urls.py
rdp new htmx <nama> -a <app>TemplateView + partial HTML HTMX
rdp new service <nama> -a <app>Class service dengan @transaction.atomic
rdp new task <nama> -a <app>Celery @shared_task
rdp new component <nama>Komponen Cotton baru
rdp scaffold <nama> -a <app>Mega generator: model + crud + api + test sekaligus
rdp makeWizard interaktif pilih generator
rdp r / m / mm / sShorthand: runserver / migrate / makemigrations / shell
rdp lintRuff check + format
rdp doctorHealth check: Python, Django check, migrasi pending
rdp releasePipeline: lint → pytest → doctor
rdp db backup / restore / reset / seedUtilitas database
rdp updateUpdate project dari template terbaru

{# ─────────────── DEPLOY ─────────────── #}

Deploy

Deploy ke VPS (Sumopod/Biznet) dengan Gunicorn + WhiteNoise. Tidak butuh Nginx untuk static files di setup dasar.

Checklist sebelum deploy

# 1. Set env production di .env
ENVIRONMENT=production
DEBUG=False
DATABASE_URL=postgresql://...

# 2. Collect static
rdp assets
# atau: uv run python manage.py collectstatic --noinput

# 3. Pipeline rilis
rdp release

# 4. Generate konfigurasi server
rdp new deploy
# → docker/deploy/nginx.conf + gunicorn.service

Jalankan Gunicorn

uv run gunicorn config.wsgi:application --bind 0.0.0.0:8000 --workers 3
