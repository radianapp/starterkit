GET STARTED

Up and running in three steps

RDP UI is plain CSS plus Django Cotton components. If you can write a Django template, you already know how to use it.

1

Install

One pip package brings the CSS, the component library, and the icon set.

$ pip install rdp-ui
# settings.py
INSTALLED_APPS = [
  "rdp_ui", "django_cotton",
]
2

Load the theme

One stylesheet, one attribute. Swap the theme by changing a single token set.

<link rel="stylesheet"
  href="{% static 'rdp/rdp.css' %}">
<body data-rdp-theme="default">
3

Use components

Every component is a Cotton tag with attributes as props and named slots.

<c-rdp.card>
  <c-slot name="header">Team</c-slot>
  <c-rdp.button variant="primary">
    Save</c-rdp.button>
</c-rdp.card>
INTERACTIVITY

Need dynamic behavior? Add hx-get / hx-post to any component — loading states, validation re-renders, and toasts are built in. See the HTMX Interaction Patterns.
