Typography system

Spacing system

Every gap, padding, and margin is a multiple of 4px, drawn from nine tokens. If a design needs a value between steps, the design is wrong — snap it.

RDP UI Foundations · Sheet 04
v0.1

Radius system

Soft, never bubbly. Nesting rule: inner radius = outer radius − padding, floored at xs.

--rdp-radius-xs · 4
Checkboxes, tags, kbd, nested elements
--rdp-radius-sm · 6
Buttons, inputs, selects, menu items
--rdp-radius-md · 10
Cards, alerts, popovers, dropdowns
--rdp-radius-lg · 14
Modals, drawers, command palette
--rdp-radius-xl · 20
Hero panels, feature tiles, empty states
--rdp-radius-pill · 999
Badges, avatars, switches, filter chips

Themes may shift the whole system with one multiplier (--rdp-radius-scale): 0 for a sharp enterprise look, 1 default, 1.5 for a friendly consumer look.

Elevation system

Two-layer shadows: a tight contact shadow plus a wide, very soft ambient one — tinted with the ink color, never pure black. Elevation communicates layer, not importance.

--rdp-shadow-1
Rest
Cards, inputs, table containers
0 1px 2px ink/5%
--rdp-shadow-2
Raised
Dropdowns, popovers, hover lift
0 1px 2px ink/4%
0 4px 12px ink/7%
--rdp-shadow-3
Overlay
Modals, drawers, command palette
0 2px 6px ink/5%
0 12px 32px ink/10%
--rdp-shadow-4
Peak
Toasts, onboarding spotlight
0 4px 12px ink/6%
0 24px 56px ink/14%
Border elevation — flat contexts

Dense tables, sidebars, and print use borders instead of shadows: --rdp-elevation-border: 0 0 0 1px var(--rdp-border). Combine with shadow-1 for cards that must read on tinted backgrounds.

border only
border + shadow-1
Dark mode rule

Shadows barely read on dark surfaces. Elevation switches to surface steps — each layer up uses a lighter surface token plus --rdp-border. Same tokens, remapped by the theme.

Iconography

Quiet line icons that sit beside text without shouting. Icons inherit currentColor — they are text, tinted by the same tokens.

Construction
Grid: 24 × 24, 2px safe area
Stroke: 1.75px, non-scaling
Caps & joins: round
Corners: 2px optical rounding
Fill: none — -fill suffix for solid variants
Naming & usage
Kebab-case: object-modifier
