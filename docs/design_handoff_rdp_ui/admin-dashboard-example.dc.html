Composition notes
Everything is an RDP component — app shell, stat cards, chart container, table, badges, notification timeline, toasts. Zero custom CSS in the example app.
Desktop → mobile: sidebar becomes drawer + bottom nav, KPI row 4→2×2, table rows become cards (order + amount survive; columns drop by priority).
Live regions: KPIs and the orders table refresh via hx-trigger="every 60s"; the notification badge swaps out-of-band.
Touch targets: all mobile taps ≥ 44px; bottom-nav labels always visible.
