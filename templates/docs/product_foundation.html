The UI framework Django never shipped.

A complete, server-first UI ecosystem — design system, CSS framework, Cotton components, HTMX patterns, themes, and templates — built natively for Django. Modern UI Framework for Django.

01

Product positioning

For Django teams who want a polished product without adopting a frontend stack, RDP UI is the UI framework that turns semantic HTML into a finished interface — components, themes, and interaction patterns that speak Django natively.

Unlike CSS toolkits that stop at styling, or component libraries that assume React, RDP UI covers the whole surface of a real product — from a button to a billing page — inside the templates Django developers already write.

Framework What it is Why it falls short for Django teams
Tailwind UI Paid component gallery on utility-class CSS Utility-class soup in templates; React/Alpine-leaning; no Django integration
shadcn/ui Copy-paste React components Requires the React + build-tool stack Django teams are avoiding
PicoCSS Elegant classless CSS for semantic HTML Stops at primitives — no components, patterns, or product templates
Bootstrap The long-standing default CSS framework Instantly recognizable, dated look; no server-first interaction story
RDP UI Complete UI ecosystem for Django Design system → CSS → Cotton components → HTMX patterns → themes → templates, one coherent stack
The wedge

The only complete UI ecosystem natively built for Django + Cotton + HTMX. Every component is one tag away — <c-rdp.button> — with server-first interactivity and zero build step.
