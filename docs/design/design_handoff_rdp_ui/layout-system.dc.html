Container & grid

Semantic layout, not utility soup: <c-rdp.container> centers and caps width; <c-rdp.grid> is a 12-column CSS grid with token gaps.

--rdp-container-sm: 640px;  --rdp-container-md: 768px;  --rdp-container-lg: 1024px;  --rdp-container-xl: 1280px;
--rdp-container-prose: 68ch;  --rdp-grid-gap: var(--rdp-space-5); /* 24px, drops to space-4 below md */

RDP UI Foundations · Sheet 11
v0.1 · mobile-first

Responsive strategy

Mobile-first: base styles are the phone layout; breakpoints only ever add space and columns. The shell degrades by shedding chrome, never by shrinking touch targets.

--rdp-bp-sm: 640px;  --rdp-bp-md: 768px;  --rdp-bp-lg: 1024px;  --rdp-bp-xl: 1280px; /* min-width queries only */
< 640 · Mobile
Sidebar → drawer via hamburger. One column. Right panel hidden.
≥ 768 · Tablet
Icon rail (64px). Two-up cards. Search collapses to an icon.
≥ 1024 · Desktop
Full sidebar (224px). Three-up cards. Full search field returns.
≥ 1280 · Large
Right panel appears. Content caps at container-xl, centered.
Collapse order
Right panel → sidebar to icon rail → sidebar to drawer → search to icon. Content is never sacrificed for chrome; drawers overlay with a scrim and trap focus.
Touch rules
Targets ≥ 44 × 44px with ≥ 8px between them · inputs ≥ 16px font on mobile (no iOS zoom) · hover-only affordances always have a tap equivalent · sticky bars respect safe-area insets.
