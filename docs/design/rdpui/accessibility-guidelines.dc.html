Accessibility guidelines

Accessibility is a component contract, not a checklist at the end. Every <c-rdp.*> ships these behaviors by default — a developer has to work to make an RDP app inaccessible.

WCAG 2.2 AA commitments
1.4.3 · Contrast
Text ≥ 4.5:1, large text & UI graphics ≥ 3:1 — enforced per theme in CI. Every built-in theme ships a published contrast report.
2.1.1 · Keyboard
Everything operable by keyboard alone, no traps except intentional dialog traps. Skip-link is the first tab stop of every app shell.
2.4.7 / 2.4.11 · Focus
2px ring, 2px offset, on every control — never outline: none without replacement. Focused element never hidden under sticky chrome.
2.5.8 · Target size
Interactive targets ≥ 24px always; ≥ 44px on coarse pointers via @media (pointer: coarse) baked into the tokens.
1.3.1 · Semantics
Real elements first: button, nav, table, dialog, details. ARIA only where HTML has no native answer.
4.1.3 · Status messages
Every async result is announced: toasts, search counts, validation summaries — via live regions, without moving focus.
1.4.10 / 1.4.4 · Reflow
Layouts reflow to 320px and survive 200% text zoom — sizes in rem, no fixed-height text containers.
2.3.3 · Motion
prefers-reduced-motion collapses all durations to 1ms (Sheet 26). No parallax, no autoplay.

Cotton components render these automatically from their props — <c-rdp.field :field="form.email"> wires label, ids, describedby and invalid state with zero developer effort.
Focus management — overlays
F1
Open: modal/drawer focus goes to the first meaningful control — never the close ×, never a destructive button. If content loads via HTMX, focus waits for the swap.
F2
While open: background is inert; screen-reader virtual cursor can't wander out; scroll is locked.
F3
Close: focus returns to the trigger. If the trigger was removed by a swap (e.g. deleted row), focus moves to the nearest surviving sibling, else the region heading.
F4
Toasts never take focus. They announce via live region; their actions are reachable but optional. Anything requiring a decision is a dialog, not a toast.
F5
HTMX swaps preserve focus when the focused element survives (matched by id); otherwise focus lands on the swapped region's first heading or the validation summary.
Color independence
Active Status = color + text (+ dot shape). Never a bare colored dot.
⚠Enter a full email Errors = red + icon + message + aria-invalid, never border color alone.
MRR Sorted column = color + arrow + aria-sort; deltas = color + ↑↓ glyph.
Text links Links inside prose are underlined — color is never the only cue.
Chart series pair color with direct labels or patterns — legends alone don't survive greyscale.
