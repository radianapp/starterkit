Layout System

4 layout Cotton berlapis — pilih sesuai konteks halaman. Semua extend <c-layout.base>.

{# ── 4 LAYOUT CARDS ── #}
<c-layout.blank>

Halaman tanpa navigasi. Cocok untuk: login, register, reset password, halaman error.

Tidak ada navbar/sidebar
<c-layout.blank title="Masuk">
  {# konten halaman #}
</c-layout.blank>

Slot System

Layout app punya slot yang bisa diisi dari template halaman:

<c-layout.app title="Halaman Saya">
  <c-slot name="sidebar">
    <c-sidebar.brand title="App" />
    <c-sidebar.nav>…</c-sidebar.nav>
  </c-slot>

  <c-slot name="navbar_actions">
    <c-rdp.button variant="primary">Simpan</c-rdp.button>
  </c-slot>

  <c-slot name="head">
    <link rel="stylesheet" href="…page-specific.css">
  </c-slot>

  {# konten utama halaman di sini #}
</c-layout.app>
