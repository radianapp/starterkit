{# ── INTRO ── #}

RDP CLI

CLI global untuk Radian Data Platform. Bootstrap project baru, generate kode boilerplate, jalankan perintah Django — semuanya dari terminal tanpa buka editor.

Install global via uv:

uv tool install git+https://github.com/radianapp/starterkit.git

Verifikasi:

rdp --version
{# ═══════════════════════════════════════════════════════ #} {# 1. PROYEK BARU #} {# ═══════════════════════════════════════════════════════ #}

⚡ Proyek Baru

Perintah untuk bootstrap project Django baru dari template RDP atau memperbarui project yang ada.

Wizard interaktif untuk membuat project Django baru dari awal. Clone template, setup .env, pilih fitur a-la-carte.

$ rdp new portal-analytic
# Wizard akan tanya: nama, deskripsi, warna aksen, fitur
# ✓ Landing Page? ✓ Auth UI? ✓ Dashboard UI?
Apa yang dilakukan:
  1. Clone radianapp/starterkit dari GitHub (shallow clone)
  2. Hapus .git/ — project baru bersih, tidak terhubung ke repo template
  3. Generate SECRET_KEY baru + isi .env otomatis
  4. Update pyproject.toml dengan nama & deskripsi project
  5. Hapus modul yang tidak dipilih (landing/auth/dashboard bisa opt-out)
Butuh Git + koneksi internet

Update project yang sudah ada dengan versi template terbaru. Jalankan dari root project (sejajar manage.py).

$ cd nama-project
$ rdp update
# File berbeda → ditanya: overwrite? [y/N/d (diff)]

◈ Generator Kode

Generate file boilerplate sesuai konvensi RDP. Semua rdp new * di bawah ini dijalankan dari root project. Flag -a <nama-app> menentukan app target.

{# Tabel ringkas #}
Perintah Buat apa Contoh
rdp new app <nama> Django app dengan struktur package (models/, views/, services/, forms/, admin/, tests/) rdp new app products
rdp new model <nama> -a <app> File model di apps/{app}/models/{nama}.py + auto-export di __init__.py rdp new model product -a products
rdp new crud <nama> -a <app> ListView + CreateView + UpdateView + DeleteView + template list & form rdp new crud product -a products
rdp new api <app> Skeleton DRF: folder api/views/, api/serializers/, api/urls.py dengan router rdp new api products
rdp new htmx <nama> -a <app> TemplateView + partial HTML di templates/{app}/partials/{nama}.html rdp new htmx product_table -a products
rdp new service <nama> -a <app> Class service di apps/{app}/services/{nama}.py dengan @transaction.atomic rdp new service stock_manager -a products
rdp new task <nama> -a <app> Celery @shared_task di apps/{app}/tasks.py rdp new task sync_stock -a products
rdp new command <nama> -a <app> Custom management command di apps/{app}/management/commands/{nama}.py rdp new command import_csv -a products
rdp new test <nama> -a <app> File pytest di apps/{app}/tests/test_{nama}.py rdp new test product_service -a products
rdp new component <nama> File HTML Django-Cotton di templates/cotton/rdp/{nama}.html rdp new component price_tag
rdp new page <nama> -a <app> Template HTML halaman penuh dengan <c-layout.app> rdp new page report -a products
rdp new seeder <nama> -a <app> Management command seeder berbasis Faker untuk mengisi data awal rdp new seeder product -a products
rdp new permission <nama> -a <app> Class DRF permission (CanView, CanCreate, CanUpdate, CanDelete) di permissions.py rdp new permission product -a products
rdp new env Salin .env.example ke .env.development, .env.production, .env.staging, .env.testing rdp new env
rdp new docker Dockerfile + docker-compose.yml siap pakai (Python 3.12, PostgreSQL 15) rdp new docker
rdp new deploy Konfigurasi deployment: nginx.conf + gunicorn.service (systemd) rdp new deploy
rdp new docs Template dokumentasi: API.md, CHANGELOG.md, CONTRIBUTING.md, README.md rdp new docs
{# Shortcut: make + scaffold #}

Wizard interaktif — pilih apa yang mau dibuat dari menu bernomor. Cocok kalau lupa sintaks.

$ rdp make
1. App 2. Model 3. CRUD
4. API 5. Component 6. Task
7. Service 8. Test

Mega generator — jalankan model + crud + api + test sekaligus dalam satu perintah.

$ rdp scaffold product -a products
# → model + crud + api + test dibuat sekaligus
{# ═══════════════════════════════════════════════════════ #} {# 3. DJANGO WRAPPER #} {# ═══════════════════════════════════════════════════════ #}

▦ Django Wrapper

Shorthand untuk perintah uv run python manage.py … yang sering dipakai. Semua dijalankan dari root project.

Jalankan dev server Django.

$ rdp r
# → uv run python manage.py runserver

Terapkan migrasi database.

$ rdp m
# → uv run python manage.py migrate

Buat file migrasi baru dari perubahan model.

$ rdp mm
# → uv run python manage.py makemigrations

Buka shell interaktif Django.

$ rdp s
# → uv run python manage.py shell
{# ═══════════════════════════════════════════════════════ #} {# 4. QUALITY & DATABASE #} {# ═══════════════════════════════════════════════════════ #}

◎ Quality & Database

Jalankan Ruff: linter + formatter sekaligus.

$ rdp lint
# ruff check . && ruff format .

Health check: versi Python, Django check, migrasi yang terlewat.

$ rdp doctor
# [1/3] Python [2/3] Django check
# [3/3] Cek migrasi pending

Cek library yang perlu di-update (uv pip list --outdated).

$ rdp upgrade

Status disk sistem dasar (total / used / free).

$ rdp monitor

Utilitas database — backup, restore, reset, seed, shell.

Sub-perintah Fungsi
rdp db backup [file]Export seluruh data ke JSON (dumpdata)
rdp db restore <file>Import data dari file JSON (loaddata)
rdp db resetHapus db.sqlite3 + migrate ulang (dengan konfirmasi)
rdp db seedJalankan loaddemodata management command
rdp db shellBuka database shell langsung (dbshell)
{# ═══════════════════════════════════════════════════════ #} {# 5. DEPLOY & RILIS #} {# ═══════════════════════════════════════════════════════ #}

◐ Deploy & Rilis

Kumpulkan static files (collectstatic) + kompres (compress). Dijalankan sebelum deploy production.

$ rdp assets

Pipeline rilis: lint → pytest → doctor. Gagal di salah satu langkah → proses berhenti.

$ rdp release
# [1/3] lint [2/3] pytest [3/3] doctor

Bangun app demo inventory lengkap — app + api + komponen + service + task + test. Berguna untuk eksplorasi semua generator sekaligus.

$ rdp build-demo

Referensi Cepat

# Bootstrap project baru
rdp new nama-project

# Tambah app baru
rdp new app orders

# Scaffold lengkap (model + crud + api + test)
rdp scaffold order -a orders

# Dev workflow harian
rdp r                 # runserver
rdp mm && rdp m      # makemigrations + migrate
rdp s                 # shell

# Sebelum push
rdp lint && rdp release

# Bantuan
rdp --help
rdp --version
