{# ============ CARA PAKAI ============ #}
MULAI

Jalan dalam 3 langkah

Tidak perlu setup dari nol. Clone, isi .env, migrate — langsung jalan.

1

Clone & install

Butuh Python 3.11+ dan uv. Semua dependency dikelola via uv.

$ git clone https://github.com/radianapp/starterkit
$ cd starterkit && uv sync
2

Config .env

Salin .env.example, isi SECRET_KEY dan database. Semua setting via environment variable.

$ cp .env.example .env
# Edit SECRET_KEY, DATABASE_URL
$ uv run python manage.py migrate
3

Jalankan

Dev server langsung jalan. Tambah app baru via uv run python manage.py startapp.

$ uv run python manage.py createsuperuser
$ uv run python manage.py runserver

{# ============ TECH STACK ============ #}
STACK

Teknologi yang dipakai

Dipilih untuk keandalan, produktivitas solo developer, dan deployment ke VPS tanpa vendor lock-in.

◈ Django Latest stable. CBV untuk CRUD, function view untuk HTMX endpoint.
▦ uv Package manager 10-100x lebih cepat dari pip. Lock file untuk reproducible build.
◎ PostgreSQL Production. SQLite untuk development — tidak perlu Docker hanya untuk dev.
▤ RDP-UI + PicoCSS Zero build step. CSS variables, 11 tema, komponen Cotton — tidak butuh Node.js.
◐ Gunicorn + WhiteNoise Deploy ke VPS langsung. Static files via WhiteNoise — tidak butuh Nginx untuk static.
