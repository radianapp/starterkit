Button

Triggers an action. Use a button for actions, a link for navigation — if it changes the URL, it's a link. One primary button per view; everything else is secondary or quieter.

Accessibility

· Renders a real <button> — Space/Enter, focus and disabled semantics are native. · While loading: aria-busy="true", label change announced; width locked so nothing shifts. · Icon-only usage requires aria-label — the component raises in DEBUG without it. · Focus ring: 2px ring / 2px offset on :focus-visible in every theme.
